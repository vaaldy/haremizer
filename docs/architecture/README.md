# Architecture

- [Image-world-model concept](image-world-model.md), also available as
  [self-contained HTML](image-world-model.html) and [PNG](image-world-model.png)

The image-world-model drawing is a **concept illustration, not automatic detection**.
Its red outline-only boxes illustrate candidate regions, not detected body parts.
Semantic classification, automatic part maps and image-model expression regeneration
in that drawing are planned, not an implemented public API. Existing source-bound
annotation/edit tools do not make the whole illustrated system operational.
The PNG and self-contained HTML retain their original bytes, including embedded
images and relative links. The Markdown companion differs only by removal of one
trailing blank line; its content and relative links are unchanged. The illustration's Mint artwork has the same
unresolved generated-sample rights boundary described in [sample provenance](../samples.md).
